# CLAUDE.md — Визитка Марга АСТ

## Технические правила

- **Один HTML-файл** — весь код живёт в `vizitka.html` (HTML + `<style>` + `<script>` inline)
- **Без внешних библиотек** — только ванильный JS и CSS; шрифты через Google Fonts
- **Адаптив обязателен** — мобильный first; breakpoints: 480px; ничего не ломается на телефоне
- **Фото** — файл `photo.jpg.jpg` (двойное расширение, это баг) — при чтении использовать `src="photo.jpg.jpg"` до переименования, или переименовать в `photo.jpg`

## Стиль текста на странице

- Простой, живой, без канцелярита
- Говорим «ты», не «вы»
- Короткие предложения

## Дизайн-система

### Референс

**Razorpay Sprint'26** — https://razorpay.com/sprint/26
Электрический синий (#0039FF) как ОСНОВНОЙ фон. Чёрные карточки на синем. Белый текст. Максимальный контраст. Острые края, 0 border-radius. Высокая энергия.

### Цветовая палитра

```css
:root {
  --bg:      #0039FF;   /* ГЛАВНЫЙ фон — электрический синий */
  --card:    #000000;   /* карточки — чёрные на синем */
  --white:   #FFFFFF;   /* основной текст */
  --muted:   rgba(255,255,255,.5);  /* приглушённый текст */
  --ink:     #000000;   /* текст на светлых/синих блоках */
}
```

Оранжевый убран. Акценты — только белый и чёрный на синем.

### Типографика

**Только Roboto Condensed** — один шрифт, иерархия через размер:

- Hero-заголовок: `clamp(5rem, 22vw, 9rem)` — имя МАРГА АСТ
- Секционный заголовок: `clamp(2.8rem, 12vw, 5rem)` — ПОЧЕМУ ЭТО РАБОТАЕТ
- Число/метрика: `clamp(3rem, 14vw, 5.5rem)` — −60%, ×3
- Подзаголовок: `clamp(1rem, 4vw, 1.4rem)` — названия карточек
- Label/eyebrow: `0.7rem`, `letter-spacing: .28em` — МЕТОДОЛОГИЯ, КЕЙСЫ

Все тексты uppercase. Трекинг на лейблах `.28em`, на заголовках `.04em`.

### Карточки

```css
/* Карточка на синем фоне */
background: #000;
border-radius: 0;        /* острые углы */
border: none;
padding: 1.5rem 1.8rem;
```

### Анимации

- Вход: `fade-up` + `cubic-bezier(.34,1.56,.64,1)`, opacity + translateY
- Scroll trigger: IntersectionObserver + класс `.visible`
- Stagger: delay +0.09s на каждый следующий элемент
- Hover: `translateY(-4px)` или `translateX(5px)` — только transform, никаких цветовых transition

### Компоновка

- Колонка: `min(520px, 92vw)`, центрирована
- Секции разделены тонкой линией `rgba(255,255,255,.12)`
- Отступы: `padding: clamp(3.5rem, 9vw, 6rem) 1.5rem`
