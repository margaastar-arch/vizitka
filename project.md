# Визитка — Марга АСТ (актуальная версия)

> Это рабочая, задеплоенная версия сайта-визитки. Старая папка `~/projects/vizitka/` устарела (тёмно-синий дизайн, Montserrat, частицы) — здесь описан реальный продакшн.

## Что это за проект

Персональная одностраничная визитка Марги АСТ — специалиста по внедрению ИИ в бизнес.
Позиционирование: «Внедрение ИИ: от идеи до профита». Задача страницы — за один экран создать сильное первое впечатление и увести клиента в Telegram или WhatsApp.

## Для кого

Владельцы бизнеса и эксперты, которые хотят внедрить ИИ в процессы и ищут специалиста с системным подходом и измеримым результатом.

## Деплой

- Хостинг: Vercel, URL https://vizitka-work.vercel.app
- GitHub-репо: `margaastar-arch/vizitka.git` (remote origin этой папки)
- Деплоится файл `index.html` (Vercel берёт его как точку входа). Автодеплой при `git push`. CLI `vercel` не использовать (см. memory/feedback_vercel-deploy.md).
- Фото: `photo.jpg` (сжато до ~27 КБ).
- Единственный исходник страницы — `index.html`. Дубль `vizitka.html` удалён 2026-06-22, чтобы не путаться.

## Структура (4 блока)

1. Hero — крупное имя МАРГА АСТ капслоком, круглый аватар, тэглайн «Внедрение ИИ: от идеи до профита», две иконки-кнопки (Telegram + WhatsApp).
2. Методология «Почему это работает» — 4 карточки, каждая открывает модальное окно с подробным текстом:
   - 01 Не точечно — системно
   - 02 Только то, что окупается
   - 03 Результат через 2 недели
   - 04 Эффект без зависимости
3. Кейсы «Что уже работает» — 3 карточки с крупной цифрой результата:
   - −60% обращений в поддержку (чатбот вместо колл-центра, интернет-магазин)
   - ×3 скорость производства контента (контент-агентство)
   - 40ч/мес сэкономлено (автоматизация отчётов, производство)
4. CTA «Напиши мне — обсудим твой проект» — две кнопки (Telegram + WhatsApp).

## Дизайн (актуальный)

| Параметр | Значение |
|---|---|
| Шрифт | Roboto Condensed (300–900), узкий рубленый |
| Фон | `#0039FF` — яркий синий электрик |
| Карточки | `#000000` — чёрные |
| Текст | белый `#FFFFFF`, приглушённый `#c6c8d7` |
| Акценты | сиренево-фиолетовые `#767bd6`, `#716fb0`, `#a2a6ed` |
| Анимация фона | волны (wave canvas) внизу экрана + мерцающие «звёздочки»-капы |
| Анимации входа | fade-up, pop-in (аватар), появление карточек по скроллу через IntersectionObserver |
| Заголовки | крупные, капслоком, большой letter-spacing — плакатная подача |
| Настроение | смелое, контрастное, техно-плакат (не «тёмный премиум») |

## История дизайна

Первая версия (в старой папке `~/projects/vizitka/`): тёмно-тёмно-синий фон `#07223d`, Montserrat, частицы flow field, glassmorphism. Полностью переделано → текущая яркая плакатная версия.
